# Reddit / Quora / 论坛摘录

Reddit 有 `uv run mining fetch --keyword` 自动抓;Quora 和小论坛直连不稳,人工摘录最省事。

不要只收结论,要保留用户原话和上下文(真实生活场景、替代方案、长期痛点)。

**格式:一条原话一行,以 `> ` 开头,analyze 会自动识别。示例(代码块里的不算数):**

```text
> I've tried a vacuum, tape, gloves... the hair is woven INTO the fabric
来源:reddit r/dogs · 链接 · 初步判断:车内场景没有被现有产品解决
```
